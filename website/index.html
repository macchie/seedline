QUICK FAQ

Good to
know.

Got a question we missed? The game is still taking shape — check back as new builds arrive.

How do track seeds work?

A seed is a 16-character code used to generate a track. The same code always recreates the same layout, scenery and pickups, so you can share a circuit and compare runs fairly.

Can I play offline?

Yes. Racing, saved tracks and personal bests all work offline. Online leaderboards and rival ghosts need a connection; finished runs queue for upload when you’re back online.

What are the controls?

Keyboard, gamepad and touch are all supported. Keyboard and gamepad bindings can be changed in Options, and mobile controls are designed for thumbs.

Is it open source?

Yes. Seedline is built in GDScript on Godot 4.7 with a Nakama backend for online services. You can clone the repository and run it locally today.

What does “rival ghost” mean?

A ghost is a translucent recording of a best run. Follow your own replay or line up against the fastest recorded opponents on the same seeded track — up to ten at once.
