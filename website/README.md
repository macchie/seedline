# Seedline website

The landing page is a small, static Vite application. Its screenshots are captures from the
running Godot game in `public/screenshots/`.

## Local development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it locally with `npm run preview`.
The generated site is written to `dist/`.

Official platform builds have not been published yet. The download cards are intentionally
disabled until verified release URLs are available.
